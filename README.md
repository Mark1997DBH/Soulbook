因微信小程序原生环境**不支持直接运行 SQLite 数据库**（SQLite 通常用于 iOS/Android 原生 App），为了符合微信小程序开发规范并确保项目可执行，我将采用**微信小程序本地存储 (Storage)** 方案来构建一个模拟的数据库层。

该方案将完全满足您“存储数据”、“直接放在项目里（纯本地运行）”以及“分析情绪”的需求，同时保持页面简洁可爱。

### 1. 核心技术方案
*   **数据存储**：封装 `wx.setStorageSync` 和 `wx.getStorageSync`，构建一个 `MoodDB` 类。
    *   模拟数据库表结构，以 JSON 格式存储心情记录。
    *   无需搭建服务器，数据完全保存在用户手机本地，符合隐私合规要求。
*   **UI 风格**：
    *   **关键词**：圆润、卡片化、柔和配色（马卡龙色系）。
    *   **图标**：使用 Emoji 或 CSS 绘制的简单表情，确保无需额外下载图片资源，保持包体积小巧。
*   **开发框架**：原生微信小程序 (WXML, WXSS, JS)。

### 2. 项目目录结构设计
```text
/
├── app.json            # 全局配置（页面路由、窗口表现）
├── app.wxss            # 全局样式（定义可爱的主题色、通用字体）
├── app.js              # 全局逻辑
├── utils/
│   ├── db.js           # 【核心】数据访问层，模拟 SQLite 的增删改查接口
│   └── util.js         # 日期格式化等工具
├── pages/
│   ├── index/          # 【首页】心情日历/列表，展示每天的心情概览
│   ├── add/            # 【记录页】选择心情（开心/平淡/难过等）、写日记
│   └── stats/          # 【分析页】情绪变化统计（柱状图/饼图）
└── images/             # 存放必要的静态资源（如有）
```

### 3. 功能模块规划
#### A. 数据层 (utils/db.js)
将实现以下类似数据库的方法，方便调用：
*   `addRecord(record)`: 新增一条心情记录（包含日期、心情类型、备注）。
*   `getRecordsByMonth(year, month)`: 获取指定月份的所有记录。
*   `getStatsData()`: 获取情绪分布统计数据。

#### B. 界面设计 (UI)
*   **配色方案**：
    *   开心：☀️ 暖黄 (#FFD93D)
    *   平淡：🍃 薄荷绿 (#6BCB77)
    *   难过：🌧️ 雾霾蓝 (#4D96FF)
    *   生气：🔥 珊瑚红 (#FF6B6B)
*   **首页 (index)**：顶部显示当前日期，中间是卡片式的日历或列表，每一天显示对应的心情颜色块。
*   **记录页 (add)**：大大的心情图标选择器，简单的圆角输入框。
*   **分析页 (stats)**：使用 CSS 绘制简单的比例条，直观展示“本月开心了几天”。
